# Install the Grok Memory skill

Minimal clicks. Happy tone.

## Steps

1. Open **Grok** (web, iOS, or Android) while signed in.
2. Go to **Settings → Skills** (or open **Skill Creator**).
3. **Create** a skill.
4. Set the **name** to `Grok Memory`.
5. Paste the **description** and **instructions** from `GROK_MEMORY_SKILL.md` (or use the copy buttons on the website `/skill` page).
6. **Save**.
7. In any chat, say: **Remember this skill**
8. When you finish a chat you care about, say: **Save this**

## After install

- You do **not** reinstall every conversation.
- Still use the start and end phrases—they keep the ritual clear.
- For your full history: follow the short in-chat steps after **Save this**, then open **Grok Backup Memory → Import**.

## If Grok doesn’t pick up the skill

Try once: **Run remember this skill**

We do not use slash commands (`/…`) in this product.
